Five questionsThings I will not guess at.

1. What is the live definition of the star rating?

The Explore filter tooltip says 5 stars is "Top 10% of brand, 14+ days" and 4 stars is "Top 25% of brand, 7+ days". That is a within-brand percentile. What we were told previously was days active plus shared-creative count. Those are different things, and it matters: a small brand's top 10% is not necessarily a strong ad. The prompt library we are about to ship says "5-star ads (GetHookd's Winning performance rating)" throughout, so I want the right wording.

2. Is the Chat credit cost expected?

Chat costs 2.62 credits for a three-ad answer. The same question through the MCP costs roughly 0.15 to 0.5. That is 5 to 17 times more for a comparable result. It changes how hard we push Chat versus the agent route.

3. Do board and swipe-file records carry run time and live status?

Three prompts in the library lean on it and currently have a say-so fallback.

4. Does the API return carousel as an ad format?

I dropped it from one prompt rather than guess.

5. Advertorial landing page type returned zero

Filtering Explore by landing page type Advertorial returned nothing on a query whose own results contain advertorials. Seen once, not yet re-tested, so treat as unconfirmed until I reproduce it.

One ask that shrinks everything

Put the headline and the link text on the search result row.

If search results carried those two fields, we could delete a sentence from all 45 prompts in the library and most of them would drop to a single call. Right now every prompt has to tell the AI to go and read them, which is the main thing making them slow. Highest-leverage change on my list.
